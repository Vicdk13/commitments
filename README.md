# Домовленості з запису

Завантажуєш запис робочої розмови двох людей — отримуєш список **фінальних** зобов'язань: задачі, власники, дедлайни, скасоване, неприйняті пропозиції, відкриті питання. Кожен пункт підкріплений дослівною цитатою з таймкодом, яку можна прослухати.

Це не саммарі зустрічі. Апка навмисно **не** перетворює «ми могли б» на «ми зробимо», не залишає скасоване активним і не вигадує власника чи дату, яких не називали. Якщо домовленостей немає — так і каже.

**Демо:** https://commitments-jet.vercel.app · **Відео:** https://youtu.be/G_-0se1jgd0 · Нотатки для перевіряючих: [NOTES.md](NOTES.md)

## Як працює

```
аудіо (≤3 хв, 2 спікери)
  → ElevenLabs Scribe v1: текст + пословні таймкоди + хто говорить      ~3–8 с
  → Claude Opus 5 (або Sonnet 5 на вибір; structured output за схемою): домовленості ~20–30 с
  → сервер прив'язує кожну цитату до секунд по словах Scribe (модель не вгадує час)
  → UI: доріжка розмови з маркерами рішень, розшифровка з рішеннями на місці, підсумок, час/вартість
```

Обмеження прототипу (за брифом): одна мова в записі, два спікери, до 3 хвилин, спікери представляються на початку.

## Запуск локально

```bash
npm install
cp .env.example .env   # і вписати ключі
npm run dev            # http://localhost:3000
```

`.env`:
```
ANTHROPIC_API_KEY=sk-ant-…     # console.anthropic.com
ELEVENLABS_API_KEY=…           # ключ із дозволом Speech to Text (і Text to Speech, якщо генерувати тестові записи)
```

Ключі з `.env` мають пріоритет над однойменними системними змінними (`next.config.ts`, `dotenv override`).

## Тестовий набір і перевірка

`samples/` містить три записи, згенеровані з написаних сценаріїв, і **очікувані результати, зафіксовані до тестування**:

| Файл | Що перевіряє |
|---|---|
| `01-main.mp3` (2:59) | Усі 5 обов'язкових ситуацій: неприйнята пропозиція, прийнята задача, виправлений дедлайн, скасована задача, задача без власника |
| `01b-one-change.mp3` (2:59) | Той самий запис, змінено **рівно одну** домовленість (темну тему не скасували) — у видачі має змінитись один пункт |
| `02-variant.mp3` (2:37) | Наступна розмова тих самих людей: скасоване повернули + **сарказм** («ну звісно, за вечір напишу тести»), який не має стати зобов'язанням |
| `03-no-conclusion.mp3` (1:06) | Розмова без жодної домовленості, запис обірваний — апка має **відмовитись робити висновок** |
| `04-no-names.mp3` (1:03) | Той самий діалог **без представлень** — спікери підписуються з тексту («Голос 1 · …»), без вигаданих імен |

Сценарії й очікувані таблиці — `samples/NN-*.md`; машинна версія очікувань — `samples/expected.json` (перевірки включення справжніх зобов'язань **і** виключення вигаданих).

```bash
npx tsx scripts/eval.ts            # повний прогін: STT + LLM, пише samples/eval-report.md
npx tsx scripts/eval.ts --cached   # лише LLM на збережених розшифровках
npx tsx scripts/eval.ts 02         # один файл
```

Останній звіт — [samples/eval-report.md](samples/eval-report.md).

Інші скрипти:
- `scripts/make_audio.py samples/01-main.md` — озвучити сценарій (ElevenLabs TTS, `eleven_v3`, два голоси, паузи між репліками; потрібен `ffmpeg`).
- `scripts/run_pipeline.ts samples/01-main.mp3` — прогнати один файл у консолі з таймінгами.

## Структура

```
src/app/page.tsx              UI: завантаження, кроки, результати, плеєр, розшифровка, метрики
src/app/api/transcribe        POST multipart → Scribe → репліки з таймкодами
src/app/api/extract           POST розшифровка → Claude → домовленості
src/lib/stt.ts                виклик Scribe, склейка слів у репліки
src/lib/extract.ts            промпт, схема відповіді (zod), прив'язка цитат до секунд
src/lib/models.ts             реєстр моделей аналізу, ціни, effort за замовчуванням
src/lib/pricing.ts            ціна розпізнавання
src/components/Timeline.tsx   доріжка запису: смуги спікерів, маркери рішень, курсор
src/components/Transcript.tsx розшифровка з підсвіткою цитат і картками рішень на місці
src/components/Summary.tsx    компактний підсумок збоку
src/lib/annotations.ts        зобов'язання + питання → позначки з таймкодами
src/components/Metrics.tsx    таблиця часу/вартості
```

## Що чуже, а що своє

Чуже: Next.js, React, `@anthropic-ai/sdk` (structured outputs через `zodOutputFormat`), `zod`, ElevenLabs Scribe/TTS API, `ffmpeg` для склейки тестових записів.
Своє: промпт і схема витягу, логіка статусів, прив'язка цитат до пословних таймкодів, увесь UI, сценарії, тестовий набір і eval-скрипт.
